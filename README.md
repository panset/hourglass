# Hourglass

Hourglass is an open-source token-management framework for shared lab setups.
It meters how long each developer holds a shared setup and drains a monthly
token balance faster when setups are scarce, so idle setups get released.

**Status: early development.** Nothing is usable yet. See
[docs/progress.md](docs/progress.md) for what is finished and
[docs/SPEC.md](docs/SPEC.md) for the functional specification.
