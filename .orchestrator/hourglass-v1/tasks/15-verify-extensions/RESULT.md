## Findings (severity, location, reproduction)
1. MEDIUM `tools/check_core_generic.sh:48-52` (awk import extraction). Rule 1 and rule 3 miss every single-line import except the bare form `import "path"`: `import _ "x"`, `import w "x"`, `import ( _ "x" )`, and two specs on one line inside a block (only the first quoted string is read). Repro: put `package zz\nimport _ "github.com/panset/hourglass/hooks/webhook"` in `internal/zz/a.go` -> script exits 0. Same for `cmd/zz/m.go` with `import _ "github.com/vmware/govmomi/find"` (rule 3). The blank import is exactly how an extension gets wired into core. Block-form imports are all caught (verified rule 1: providers, pressure, policies, hooks, examples, govmomi; rule 3: cmd, providers/other, providers/vspherex, pkg/other fail; providers/vsphere/sub, deploy, e2e pass). Fix: also match `^import[[:space:]]+([A-Za-z_.][A-Za-z0-9_]*[[:space:]]+)?"`, and handle one-line paren form; or use `go list -f` as the brief offered.
2. MEDIUM (test time) `pkg/hourglasstest/hourglasstest_test.go` ~41 s (wall, also `bazel test` 40.3 s). Cause: `TestEXT5_Broken{Provider,PressureSource,Policy,Hook}IsCaught` run the FULL suite (`failures(xxxChecks(...))`) against each broken impl, but `mustFail` asserts only the one named check. The slow broken impls `time.Sleep(2s)` so every other check also waits (provider: 1+4+2+10 s = 17 s; policy 11 s; pressure 9 s; hook 3 s), and the four Broken* top-level tests run serially (only their subtests are parallel). Fix (applied in the clone, patch `hourglasstest-speedup.patch`; same assertions): `failures(checks, only string)` skips every check but `c.check`, and `t.Parallel()` at the top of the four Broken* tests. Result: 2.3 s with `-race`, 1.2 s without; the remaining ~1 s is the suites' own `promptly` bound. Nothing weakened: mustFail still demands that exact check fail.
3. LOW `pressure/inventory/inventory.go:56-66`. A `+Inf` weight on a held setup gives `Inf/Inf = NaN`, returned with nil error, outside [0,1] (the clamp tests do not catch NaN). Weights summing past 1.8e308 overflow total to +Inf and silently return 0. Repro: setups a(+Inf, held), b(1). Fix: reject `math.IsInf` like NaN, or return an error / clamp when `total` or ratio is not finite.
4. LOW `policies/default/default.go:83`. The allocation trigger uses `s.AllocationFor(h.Hold.SetupName)` and ignores `HoldState.Allocation` (documented in types.go:129 as "the provider's allocation for the setup"). Consequences: a HoldState built with `Allocation` set but a Snapshot without it does not meter; a hold on a setup that was disabled after acquire (absent from `Snapshot.Setups`) never fires the allocation trigger even if the provider reports it (only time trigger / already-started). Decide which is authoritative and document; consider `h.Allocation != nil ||`.
5. LOW `hooks/webhook/webhook.go:164-168`. Secret redaction runs after the 200-byte cut, so a body whose secret straddles byte 200 leaks a prefix (`...ys3cr3`). Only matters for an endpoint that echoes the secret. Redact on a longer read, then truncate.
6. LOW `hooks/webhook/webhook.go:153-157`. Transport errors keep `host:port` (`dial tcp 127.0.0.1:55761: connect: connection refused`). Path, query and userinfo do not appear, so credentials are safe, but the brief's "URL never appears" holds only for the credential-bearing parts.
7. LOW/INFO `pkg/hourglass/event_json.go:15-17` doc says `details` is "passed through unmodified". `json.Marshal` compacts it and HTML-escapes `<`, `>`, `&` to `<` etc. Key order, numbers (`1.0`, `2e3`, 20-digit ints) and `é` are preserved and the result is semantically equal; only bytes differ. Also invalid `Details` makes `Marshal` fail (webhook returns "encode event" error; fine).
8. LOW `hooks/webhook/webhook.go:99`. `"types": []` (empty, non-nil) builds a hook that sends nothing, while omitted/null sends all. Defensible; flag for docs.
9. LOW `providers/static/static.go:77`. A file containing `null` is accepted as an empty array; an empty file is an error. Empty/`null` config gives the unfriendly `invalid config: EOF` instead of the `"path" is required` message (static.go:57, webhook.go:75).
10. INFO `policies/default/default.go:96`. Clock skew (poll time before acquire) with `start_after` 0 yields reason `waiting for 0s since acquire`. `-0` is accepted as 0.
11. INFO `tools/check_core_generic.sh:21,86`. Rule 2 is plain substring: `bufsize=4` trips `size=`. Matching the brief; word-boundary would reduce false positives. Spaces variants (`resource  pool`, `resource\npool`, zero-width) evade, expected for a grep.
