3. **nit** `internal/rules/selector.go:isValueChar`: a selector cannot express a label value containing space, `,`, `(`, `)`, `=` or `!`, although SET-3 allows any character in values. Failing input: labels `{"a":"x y"}` with selector `a=x y` is a parse error, and no selector can match that value. Recorded as a decision in 04, but it is a real limit on rule expressiveness (no quoting).
4. **nit** test names without a requirement id (CONTRACT/BRIEF rule): `TestDash_ProjectedRunOut` (metering_test.go), `TestRULE_FirstAllowanceOncePerPeriod` (ledger_test.go, no number), `TestLED_Crossings` (no number; the events table has no id, so `balance.low` would be the honest tag).
5. **nit** `ProjectedRunOut(0, 0, now)` returns false (burn is checked before balance). Matches brief and is recorded in 05, but an overdrawn user with no burn gets no "run out now" projection. Owner may want it differently.

Equivalent mutants (green, not findings): `balanceMT <= 0` -> `< 0` in `ProjectedRunOut` (balance 0 yields now either way); `!now.After(prev)` -> `now.Before(prev)` in `ChargeableElapsed` (gap 0 returns 0,false either way).
