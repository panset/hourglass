## Changes
1. `cmd/hourglassd` blank-imports `providers/vsphere` so the default binary registers the `vsphere` provider and pressure source.
2. `hourglassd check-provider [-config path]`: loads the config, builds the configured provider and pressure source through the registry, opens the database READ-ONLY if it exists (so setups and the resource-name template can be read; with no database it uses the seed file if configured, else no setups), performs one provider `List` and one `Pressure` call, and prints: matched setups (setup name, resource name), expected-but-not-reported setups, orphans (reported, matching a setup's resource name... i.e. resources matching a setup with no active hold), the count of ignored allocations, and the current raw pressure with the multiplier it would give. It writes nothing anywhere (no migrations, no samples, no events) and exits non-zero on any error. Put the logic in `internal/app` (generic: it must not mention any concrete provider) with a test using the fakes and the `static` provider; reuse the collector's matching code rather than duplicating it (export a small pure function from `internal/collector` if needed, additively).
3. Third-party entry point (EXT-5): today `hourglass.Run` only works when something links `internal/app`, which a main outside this module cannot import. Add the public package `pkg/hourglass/server` whose only job is to link the implementation (it imports `internal/app` for its side effect and documents itself); `cmd/hourglassd` imports it instead of reaching into `internal/`. `hourglass.Run` called without it must return an error whose message tells the developer to import `github.com/panset/hourglass/pkg/hourglass/server`. Prove it: a throwaway module outside the repo (in the scratchpad, with a `replace` directive) whose main imports only `pkg/hourglass`, `pkg/hourglass/server` and one toy extension, registers the extension and calls `Run` with a temp database; it must build with plain `go build` and serve `/healthz`. Record the transcript in RESULT.md. Update the `pkg/hourglass` package doc to show the import.
