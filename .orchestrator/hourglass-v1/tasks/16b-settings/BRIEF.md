# 16b internal/settings: typed admin settings and resource names
Job intent: .orchestrator/hourglass-v1/INTENT.md (read it first). Rules: .orchestrator/hourglass-v1/CONTRACT.md.
## Goal
Package `internal/settings`: the admin-editable metering settings of docs/SPEC.md ADM-2 and the "Configuration" table (rows whose "Where" is Admin UI, except setups and rate rules which have their own tables), stored in the `settings` table as one JSON value per key, with defaults, validation, and the resource-name template of SET-4.
## Behaviour
- `type Settings struct` with: `ResourceNameTemplate string` (default `{{.SetupName}}`), `DefaultWeight float64` (1; RULE-1), `DisplayLabelKeys []string` (empty; SET-6), `Bands metering.Bands` (`metering.DefaultBands()`), `DefaultAllowanceMT int64` (300 tokens = 300000), `MaxHoldsPerUser int` (2), `ReleaseRequiresTeardown bool` (true), `PollInterval time.Duration` (5m; minimum 1m), `Enforcement bool` (false = shadow mode).
- `Defaults() Settings`; `(Settings).Validate() error` returning a field-addressed error (`*FieldError{Field, Message}`) for the first problem: template must parse and execute against a sample setup and produce a non-empty name; default weight finite and >= 0; display label keys valid per `rules.ValidateLabels` key grammar, no duplicates, at most 32; bands valid; allowance >= 0; max holds >= 0; poll interval >= 1 minute.
- `Load(ctx, r Reader) (Settings, error)`: reads all keys; missing keys take defaults; unknown keys are ignored. `Save(ctx, w Writer, old, new Settings, actorID int64) (changed []Change, err error)`: validates, writes only keys whose value changed, and returns each change with key and before/after JSON so the caller can audit it (ADM-3). `Reader`/`Writer` are small interfaces satisfied by the store's settings methods (inside or outside a transaction); read internal/store for the signatures.
- A stable JSON form for the API: `MarshalJSON`/`UnmarshalJSON` on Settings with snake_case keys, `poll_interval` as a duration string ("5m0s" accepted, written as e.g. "5m"), allowance in whole tokens with decimals allowed (`default_allowance: 300`) converted to milli-tokens, bands as `{"base": 0, "steps": [{"from": 0.5, "multiplier": 1}, ...]}`. Unknown fields are rejected.
- Resource names (SET-4): `ResourceName(tmpl string, setupName string, labels map[string]string, override string) (string, error)`: a non-empty override wins; otherwise executes the Go `text/template` with `.SetupName` and `.Labels`; a missing label key renders as empty rather than "<no value>"; an empty result is an error. Cache parsed templates.
## Tests
Defaults; each validation rule; load with missing/unknown keys; save writes only changed keys and reports before/after; JSON round-trip and rejection of unknown fields; template cases including `{{.SetupName}}_X`, a label reference, override, parse error. Names cite ADM-2, SET-4, SET-6.
